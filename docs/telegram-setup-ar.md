# إعداد إشعارات Telegram

يمكن للبرنامج إرسال إشعارات تلقائية إلى Telegram عند الفواتير، الإلغاء، الخصومات الكبيرة، المصروفات، إغلاق اليوم، تغيير الأسعار، ومحاولات PIN الفاشلة.

الإرسال لا يعطّل الكاشير: تُحفظ الرسائل في Outbox داخل IndexedDB، وتُرسل عند توفر الإنترنت، مع إعادة محاولة تلقائية حتى 3 مرات.

## الطريقة الموصى بها: Cloudflare Worker

استخدام Worker يخفي Bot Token عن المتصفح. لا تضع Token داخل البرنامج إلا إذا كنت لا تستطيع استخدام Worker.

### 1. إنشاء البوت

1. افتح Telegram وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع الخطوات.
3. احتفظ بـ Bot Token بالشكل `123456789:AA...`.

### 2. تجهيز المحادثة

- للمحادثة الشخصية: أرسل `/start` إلى البوت.
- للمجموعة: أضف البوت إلى المجموعة، ثم أرسل أي رسالة في المجموعة.
- للحصول على Chat ID يمكنك إرسال رسالة إلى `@userinfobot` أو استخدام زر "اكتشاف Chat ID" في إعدادات البرنامج عند وجود Token مباشر.

### 3. نشر Worker

1. افتح <https://dash.cloudflare.com> ثم **Workers & Pages**.
2. اختر **Create** ثم **Worker**.
3. سمّه مثلًا `carwash-telegram`.
4. افتح **Edit code**، واحذف الكود الافتراضي، والصق محتوى ملف [`cloudflare-worker.js`](./cloudflare-worker.js).
5. من **Settings → Variables and Secrets** أضف:

| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Bot Token من BotFather |
| `PROXY_SECRET` | كلمة سر طويلة وعشوائية، مثل 32 حرفًا |
| `ALLOWED_ORIGIN` | `http://localhost:8080` |

يفضّل حفظ `TELEGRAM_BOT_TOKEN` و`PROXY_SECRET` كـ Secret وليس نصًا عاديًا. إذا لم تضبط `ALLOWED_ORIGIN` فسيسمح Worker بأي مصدر، وهذا أقل أمانًا.

6. اضغط **Deploy**.
7. انسخ رابط Worker، مثل:

```text
https://carwash-telegram.username.workers.dev
```

8. افتح الرابط في المتصفح. يجب أن تظهر استجابة تشبه:

```json
{"ok":true,"service":"carwash-telegram-proxy"}
```

### 4. ربط البرنامج

1. افتح البرنامج ثم **الإعدادات → الإشعارات**.
2. اترك **Bot Token** فارغًا عند استخدام Worker.
3. أدخل **Chat IDs**، ويمكن إدخال أكثر من ID مفصولًا بفاصلة.
4. أدخل **Cloudflare Worker URL**.
5. أدخل **Proxy Secret** بنفس قيمة `PROXY_SECRET`.
6. اختر مستوى الخصوصية:
   - `مختصر`: لا يُرسل رقم الهاتف أو تفاصيل الأصناف.
   - `مفصّل`: يُرسل الهاتف والأصناف عند تفعيلها.
7. اضغط **حفظ**.
8. اضغط **إرسال رسالة تجريبية**.

### 5. تشغيل الأحداث

من نفس الصفحة فعّل الأحداث المطلوبة، مثل:
- فاتورة جديدة
- إلغاء فاتورة
- خصم كبير
- مصروف جديد
- إغلاق اليوم
- تغيير سعر
- محاولة PIN فاشلة

يمكن ضبط حد "الخصم الكبير" كنسبة مئوية.

## الطريقة المباشرة بدون Worker

إذا وضعت Bot Token في البرنامج مباشرة:

- سيظهر Token في إعدادات الجهاز وقاعدة IndexedDB، وأي شخص يستطيع فتح أدوات المتصفح على الجهاز يمكنه رؤيته.
- قد تمنع بعض المتصفحات الاتصال المباشر بـ Telegram بسبب CORS.
- لا تشارك نسخة احتياطية JSON تحتوي Token دون حماية.

استخدم هذه الطريقة فقط على جهاز موثوق وشبكة موثوقة.

## حل المشاكل

**لا تصل الرسائل:**
- تأكد من وجود Chat ID واحد على الأقل.
- في المجموعات أضف البوت كعضو واطلب منه إرسال رسالة تجريبية.
- تحقق من Worker URL وProxy Secret.
- افتح Network في أدوات المتصفح وتحقق من الاستجابة.
- في Telegram، قد يحتاج البوت إلى `/start` أولًا.

**رسالة "Unauthorized":**
- قيمة `PROXY_SECRET` في Worker لا تطابق القيمة في البرنامج.

**رسالة "Origin not allowed":**
- اضبط `ALLOWED_ORIGIN` على `http://localhost:8080` أو اتركه فارغًا مؤقتًا للاختبار.

**رسائل فاشلة في Outbox:**
- اضغط "إعادة" بعد تصحيح الإعدادات.
- الإرسال التلقائي يتوقف بعد 3 محاولات للرسالة الواحدة.
- زر "مسح المرسل" يحذف الرسائل الناجحة فقط.

## ملاحظات أمنية

- لا ترفع Bot Token أو Proxy Secret إلى GitHub.
- لا تضع Token داخل `version.json` أو أي ملفات يتم نسخها في الإصدارات.
- استخدم Bot منفصلًا للبرنامج، وألغِ Token من BotFather فورًا إذا تسرب.
- خذ نسخة احتياطية دورية، وتذكر أن نسخة JSON قد تحتوي إعدادات Telegram.
